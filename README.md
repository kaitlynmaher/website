# Kaitlyn Maher – Portfolio Website

This is the professional portfolio of Kaitlyn Maher – creative strategist, actor, and writer working at the intersection of entertainment, tech, and impact.

Built with React + Tailwind CSS + Vite and deployed via GitHub Pages.

## 🚀 Live Site
[https://yourusername.github.io/my-portfolio](https://yourusername.github.io/my-portfolio)

## 🛠️ Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run locally:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Deploy to GitHub Pages:
   ```bash
   npm run deploy
   ```
